Don't Touch My Desk
It is an alarm system made with an ultrasonic sensor, servo motor and Arduino.


Components:

Arduino

Ultrasonic sensor

Servo motor

Red, yellow and green LED

Breadboard

Jumper wires

Buzzer

220 ohm resistors


How it works



The ultrasonic sensor is mounted on the servo motor and it sweeps 180 degrees, covering the perimeter around the desk.

If someone comes near the desk, the yellow LED turns on and the buzzer starts beeping.
If someone comes too close to the desk, the buzzer starts buzzing continuously and the LED turns red.



The radar is displayed using the Processing software, and the coding was done in the Arduino IDE.
